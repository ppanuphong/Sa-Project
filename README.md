# อัศวินรัตติกาล — ระบบจองโรงแรม + จับคู่บัดดี้ท่องเที่ยวด้วย AI Agent

เว็บแอปพลิเคชันที่พัฒนาตาม User Story Map (ขอบเขต **MVP** ครบทุกกิจกรรม และ **Phase 1** บางส่วน)

## วิธีรัน

ต้องใช้ **Node.js 22.13 ขึ้นไป** (ใช้ฐานข้อมูล SQLite ที่มากับ Node ไม่ต้องติดตั้งฐานข้อมูลแยก)

```bash
npm install
npm start          # เปิด http://localhost:3000
npm run reset-db   # ล้างข้อมูลแล้วสร้างข้อมูลตัวอย่างใหม่
```

### AI Agent (Claude)

ค่าเริ่มต้นใช้ **การจับคู่ด้วยกฎภายในระบบ** (ให้คะแนนจากทริปที่เมืองและวันที่ตรงกัน ความสนใจร่วม สไตล์การเที่ยว และอายุ)
ถ้าตั้งค่า API key ไว้ ระบบจะส่งผู้สมัครอันดับต้น ๆ ให้ Claude (`claude-opus-5-5`) วิเคราะห์ จัดอันดับ และเขียนเหตุผลเป็นภาษาไทย:

```bash
ANTHROPIC_API_KEY=sk-ant-... npm start
```

ถ้าเรียก Claude ไม่สำเร็จ ระบบจะกลับไปใช้ผลจากกฎโดยอัตโนมัติ ตั้งค่า `AI_AGENT=local` เพื่อบังคับใช้กฎอย่างเดียว

## ความครอบคลุมตาม Story Map

| กิจกรรม | MVP | Phase 1 ที่ทำแล้ว |
|---|---|---|
| **เข้าสู่ระบบ** | หน้าล็อกอิน/สมัครสมาชิก, ฟอร์มชื่อผู้ใช้-รหัสผ่าน, ตรวจรหัสกับฐานข้อมูล (scrypt), แจ้งเตือนเมื่อเข้าสู่ระบบไม่สำเร็จ, ปุ่มออกจากระบบ | จดจำการเข้าสู่ระบบ 30 วัน, แยกสิทธิ์ลูกค้า/ผู้ดูแล (เข้าหน้าหลักตามสิทธิ์) |
| **ค้นหาโรงแรม** | ฟอร์มปลายทาง/วันเข้า-ออก/จำนวนผู้เข้าพัก, API ดึงข้อมูลโรงแรมและห้องว่าง, กรอง (ราคา/คะแนน) และเรียงลำดับ | ปฏิทินเลือกวันที่ |
| **เลือกห้องและจอง** | รายละเอียดห้อง, คำนวณราคาตามจำนวนคืน×ห้อง, แสดงราคา, โปรโมชั่น (พัก 3 คืนขึ้นไปลด 10%), ฟอร์มข้อมูลผู้เข้าพักและความต้องการพิเศษ, บันทึกการจองสถานะ "รอชำระเงิน" | แกลเลอรีภาพห้องพัก |
| **ชำระเงิน** | ฟอร์มชำระเงิน, เลือกวิธีชำระ, ปุ่มยืนยัน, แสดงผลสำเร็จ/ไม่สำเร็จ, เชื่อม API Payment Gateway (จำลอง) | QR พร้อมเพย์ (จำลอง) |
| **ยืนยันการจอง** | อัปเดตสถานะเป็น "ยืนยันแล้ว" เมื่อชำระสำเร็จ, หน้าใบยืนยันพร้อมรหัสการจอง, ส่งการแจ้งเตือนผ่าน Notification Service | แจ้งเตือนทาง SMS (จำลอง — พิมพ์ลง console) |
| **จับคู่บัดดี้** | ฟอร์มโปรไฟล์และความสนใจ, แสดงโปรไฟล์บัดดี้, ปุ่มยืนยัน/ปฏิเสธการจับคู่, แชทกับบัดดี้ (บัดดี้ตัวอย่างตอบรับคำขอและตอบแชทอัตโนมัติ พร้อมสถานะกำลังพิมพ์) | รายงานผู้ใช้ไม่เหมาะสม, ผู้ดูแลระงับการใช้ฟีเจอร์บัดดี้ได้ |
| **AI Agent** | AI Agent ประเมินความเหมาะสมในการจับคู่ (กฎ + Claude) | — |
| **จัดการการจอง** | รายการการจอง, ส่งคำขอแก้ไขวันเข้าพัก ประเภทห้อง และจำนวนผู้เข้าพัก (กรองห้องตามจำนวนคน), ส่งคำขอยกเลิกพร้อมแสดงยอดเงินคืนตามเงื่อนไข, ถอนคำขอได้ | มีผลเมื่อผู้ดูแลอนุมัติ, คำนวณส่วนต่าง/คืนเงินอัตโนมัติผ่าน gateway |
| **ระบบผู้ดูแล** | แดชบอร์ด (การจองวันนี้, คำขอรอตรวจสอบ, ยอดคืนเงินเดือนนี้, กราฟการจอง 7 วัน, รายการต้องจัดการ), การจองทั้งหมด (ค้นหา/กรองสถานะ), อนุมัติ/ปฏิเสธคำขอแก้ไขและยกเลิก, แก้ราคา/ความจุ/จำนวนห้อง | เทียบข้อมูลเดิม-ใหม่และตรวจห้องว่างก่อนอนุมัติ, แจ้งผลลูกค้าทางอีเมล/SMS |
| **เช็คอิน/เช็คเอาท์ รีวิว** | ปุ่มเช็คอิน/เช็คเอาท์, อัปเดตสถานะ, ให้คะแนน 1–5 ดาวและรีวิว, แสดงรีวิวในหน้าโรงแรม | บันทึกคะแนนลงฐานข้อมูล, ผู้ดูแลเช็คอิน/เช็คเอาท์ให้แขกได้ |

**ยังไม่ได้ทำ (Phase 1):** ล็อกอินด้วย Google/Facebook, ลืมรหัสผ่าน, ปรับแก้ฟอร์มอัตโนมัติ, AI Agent ช่วยตรวจรายงานความไม่เหมาะสม, รีวิวเว็บไซต์

### เงื่อนไขการคืนเงิน
- ยกเลิกล่วงหน้า 7 วันขึ้นไป → คืน 100%
- ยกเลิกล่วงหน้า 3–6 วัน → คืน 50%
- ยกเลิกน้อยกว่า 3 วัน → ไม่คืนเงิน

## โครงสร้างโปรเจกต์

```
server.js                      HTTP server + เสิร์ฟไฟล์หน้าเว็บ
src/db.js                      สร้างตาราง SQLite + ข้อมูลตัวอย่าง
src/api.js                     REST API ทั้งหมด (auth, hotels, bookings, payments, buddy, admin)
src/auth.js, src/password.js   session/cookie และการเข้ารหัสรหัสผ่าน
src/services/paymentGateway.js Payment Gateway จำลอง
src/services/notificationService.js  แจ้งเตือนในระบบ + จำลองอีเมล/SMS
src/services/buddyAgent.js     AI Agent จับคู่บัดดี้
public/                        หน้าเว็บ (HTML/CSS/JavaScript, single-page app)
public/js/icons.js             ไอคอน Lucide (ISC) — สร้างใหม่ด้วย npm run icons (scripts/build-icons.mjs)
```

### สถานะการจอง
`pending` (รอชำระเงิน) → `confirmed` (ยืนยันแล้ว) → `checked_in` → `checked_out` · หรือ `cancelled`

## ข้อจำกัด (โหมดสาธิต)
- Payment Gateway, QR พร้อมเพย์, อีเมลและ SMS เป็นแบบจำลอง ไม่มีการตัดเงินหรือส่งข้อความจริง
- เช็คอินได้ทันทีเมื่อการจองยืนยันแล้ว (ไม่บังคับว่าต้องเป็นวันเช็คอิน) เพื่อให้ทดลองครบ flow ได้
- การจองที่ค้างสถานะ "รอชำระเงิน" ยังกันห้องไว้จนกว่าจะยกเลิก
- รูปโรงแรมเป็นภาพกราฟิกแทน (gradient + emoji)
